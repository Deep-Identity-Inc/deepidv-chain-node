## Confirmed invariants from shared-deps

- **Envelope hash:** `SHA-256(JCS(envelope))` after stripping any `sig`
  field. Hardcoded fixture hash:
  `03507fb35af9389513dc25baa9a8a7a609cfa240a300965187fec9426734ba26`
- **STH hash:** `SHA-256(JCS(sth))` after stripping `master_sig` (and
  legacy `sig`). Hardcoded fixture hash:
  `2c1e1d7e3898f93c355cd25866bb37f598ee19cce1b05eda049ccdbf51f2a7e7`
- **JCS canonical key order for STH:**
  `alg, checkpoint, key_id, root, segment, timestamp, tree_size, v`
- **Manifest format:** `<64 hex chars><two spaces><path><LF>`,
  sha256sum-compatible, sorted lexically by path.
- **Bundle file layout:** `MANIFEST.txt`, `envelope.json`,
  `envelope.hash`, `issuer.pem`, `labels.json`, `master.pem`,
  `merkle.json`, `onchain.json` (optional), `signature.bin`,
  `sth.json`, `verify.sh`, `merkle-walk`,
  `timestamps/{digicert,sectigo}.{tsr,ca.pem}`.
- **Verify scope (D.5):** envelope_hash, issuer_signature, TSA
  (SKIPPED, reported as literal "skipped"), merkle_inclusion,
  master_sth_signature, onchain_anchor (boolean | "absent").
- **Record types in v1:** `IDV` active.
  `BIO | DOC | ADDR` reserved for Phase 2 — included in the type union
  with a TSDoc note. `RSK | AML | AGR | ACT` NOT in the v1 union —
  semver-minor when added.
